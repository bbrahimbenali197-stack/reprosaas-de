# ReclaPro Local — version gratuite à 0 €

## Démarrer
1. Décompressez ce ZIP dans un dossier.
2. Ouvrez `index.html` dans Chrome, Firefox, Edge ou Safari.
3. Créez une réclamation : elle est sauvegardée dans le stockage local du navigateur.

Aucune installation, aucun serveur, aucune clé API et aucun compte Supabase ne sont nécessaires.

## Fonctions
- Tableau de bord et compteurs
- Création et recherche de réclamations
- Modification du statut et suppression
- Export JSON de sauvegarde
- Interface adaptée au mobile

## Limites importantes
Cette version est un prototype local. Les données restent dans le navigateur sur un seul appareil. Il n'y a ni comptes, ni synchronisation entre appareils, ni séparation multi-entreprises sécurisée, ni sauvegarde automatique distante. Ne stockez pas de données personnelles sensibles ou de réclamations réelles confidentielles. Exportez vos sauvegardes.

Cette version ne supprime aucun projet Supabase. Les projets distants doivent être supprimés séparément dans Supabase après confirmation explicite du projet exact.
